# QUALITY/QA-M2-04.md — CI Browser Test Job Specification

Implementation specification for the headless browser test runner in CI.

## Requirements
- Pinned Chromium binary execution via `CHROME_BIN`.
- Headless execution with virtual display support via Xvfb (`xvfb-run`).
- Zero live network reliance: all tests execute against local mock fixtures.
- Artifact upload: `.gate` test logs and trace bundles archived on failure.\n
