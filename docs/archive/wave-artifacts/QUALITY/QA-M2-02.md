## 2. Что именно доказывает harness

- Источник страницы — **реальный** `rust/gui-spike/ui/index.html` (не `tests/fixtures/app`),
  `app.js` и CSS отдаются байт-в-байт; подменяется только `window.__TAURI__`.
- Инъекция fake-транспорта стоит **до** `<script type="module" src="app.js">`; если маркер
  пропал из разметки — ошибка harness, а не «молча без fake».
- Локальный HTTP-сервер: только чтение, только внутри `ui/`, `403` на path traversal,
  `no-store` (ES-модули не грузятся с `file://`).
- Браузер ищется через `CHROME_BIN`/`CHROME_PATH`/`PATH`; заданный, но неисполняемый путь
  даёт `null`, а не «найдём другой». `requireBrowser()` бросает `InfraError`
  (`code: INFRA_NO_BROWSER`, `infra: true`). **Skip-пути нет.**
- Ожидания — предикаты (`waitFor`/`waitForCall`) с диагностикой (URL, последние IPC,
  `console.error`, текст страницы), без «магии sleep».
- `Page.reload` переустанавливает fake-транспорт (он в HTML), а настройки переживают
  reload в `localStorage` — это и есть доказательство M2-05.
- Аудио инструментировано: `getUserMedia` считает вызовы и **реджектит** захват;
  `AudioContext`/`play` считаются. Для сборки без voice-сервиса это ожидаемо.
- CDP-клиент — продуктовый `src/core/cdp/client.mjs` (`listTargets`/`openPage`/`evaluate`),
  второго протокола нет.

## 8. Как прогнать на машине с Chromium

```sh
# 0. Preflight: отсутствие/неисполняемость браузера = FAIL, не skip
test -x "$CHROME_BIN" || { echo "FAIL: CHROME_BIN"; exit 1; }
node --version   # ≥ 24

# 1. Только 7 M2-сценариев, строго последовательно (Chrome не параллелить)
CHROME_BIN=/usr/bin/chromium node --test --test-concurrency=1 tests/e2e/m2-*.e2e.test.mjs

# 2. Приёмка: pass 9 / fail 0 / skipped 0 (9 тест-кейсов в 7 файлах)
# 3. Meta-инвариант
node --test --test-concurrency=1 tests/meta/e2e-required.test.mjs

# 4. Полный fixture-набор + гейт (после остановки других писателей дерева)
CHROME_BIN=/usr/bin/chromium npm run gate:release
jq -e '.e2e.fixture=="met" and .acceptance.accepted==true' .gate/release-*.json
```

Любой `fail` — дефект сценария/селектора или реальный продуктовый дефект; `skip`
невозможен по конструкции. Повтор допускается 1 раз с сохранением обоих логов.

## 10. Что нельзя считать pass

- `pass 0 / fail 9` без браузера — это **infra fail**, а не «e2e зелёный» и не «нет среды»;
- зелёные unit/DOM-тесты (в т.ч. 124/124 на шиме) вместо browser-прогона;
- вердикт `passed_with_skips` или `passed_with_unmet` для fixture-контура M2;
- зелёный meta-тест как «M2 принят»: он доказывает существование/политику, но не исполнение;
- настоящий отчёт как приёмка: приёмка — только после §8 (9/9, `skipped 0`).
