## 2. Контракт (не менять)

- `Ready::parse(d)` — только payload; `Ready::from_dispatch(frame)` — `op=0`, `t="READY"`,
  `d`-map. Публичные типы — из `discord_core::ready` (реэкспорт `ready.rs`).
- Fatal только: `d` отсутствует (`Missing`); не-map `d` — `from_dispatch` → `NotReady`,
  `Ready::parse` → `WrongType`; `d.guilds` не list; `d.user` отсутствует/не map;
  `d.session_id` отсутствует/не строка. Битые элементы коллекций → skip + `diagnostics.malformed`;
  неверный тип необязательной коллекции/поля → пусто/дефолт + `ignored`; неизвестные top-level →
  `unknown_top_level`; дубликаты → last-wins, позиция первого, запись в `duplicates`. Уточнение
  по ревью P2-01 (2026-10-20): строковые поля принимают `Atom` (кроме `nil`/`true`/`false`);
  пути `ignored` — с префиксом `d.`.
- ID — `u64`; отрицательный/нечисловой ID в элементе → malformed-skip, в якорях — `InvalidId`.
- `merged_members[i]` → `guilds[i].members` по сырому индексу (карта после skip/дедупликации);
  расхождение длин и явный `[]` при непустых `guilds` → `malformed`; группа пропущенной гильдии
  не приклеивается к соседней.
- `Ready`/`Session` `Debug` не печатает `session_id`, `user_settings_proto`, `raw`.
- Запрещено: reducer/join/индексы, SQLite, REST, UI, protobuf, presence/voice, новые зависимости.

## 3. Как писать тесты

1. Тест читает реальную фикстуру:
   ```rust
   mod support;
   let ready = discord_core::ready::Ready::from_dispatch(&support::ready_fixture::load_ready()?)
   ```
   Для синтетики — `support::ready_fixture::parse_json(r#"{...}"#)`.
2. Strict TDD: сначала red-лог (`# EXIT=101`, md5 теста, копия `*-test.red.rs`), затем код,
   затем green; тест-спеку после red не менять (иначе новый red-лог).
3. Оракул — jq/md5 по фикстуре (`waves/RW-12/DESIGN-P2-01.md` §2), не текущая реализация.
4. Логи — только в `waves/RW-12/reports/<worker>-<case>-red.log/.green.log`; имена уникальны.
5. `cargo test --offline -p discord-core`, `cargo fmt --check`,
   `clippy --offline -p discord-core --all-targets -- -D warnings` — зелёные у воркера локально.
