## 2. Корневые причины выявленных дефектов (Root Cause Analysis)

### Причина 1: XML `AccessDenied` в контейнере hCaptcha
В `rust/gui-spike/ui/components/captcha-modal.js` фрейм hCaptcha загружал URL без правильного Origin или использовал статический шаблон без проксирования скриптов Cloudflare/hCaptcha, что привело к блокировке CDN hCaptcha со стороны серверов Cloudflare/AWS S3.
- **Решение**: Реализовать локальный мост `hcaptcha-bridge.html` с валидным Discord Origin, правильной загрузкой официального SDK `https://js.hcaptcha.com/1/api.js` и параметрами `sitekey`, `rqdata`, передаваемыми в `hcaptcha.render()`.

### Причина 2: Ошибка Discord 2007 при просмотре стрима
В логах GDB и сетевой трассировке зафиксировано, что `pollAudioDeviceLevels` в UI каждую секунду вызывал `syncVoiceMuteStateWithBackend()`, который слал `voice_connect` без проверки изменений (dirty-checking). Каждый `voice_connect` отправлял шлюзу Discord кадр OP 4 `VOICE_STATE_UPDATE` и сбрасывал сессию коалесценции RTC.
Медиа-сервер Discord при получении постоянных OP 4 для активного стримера сбрасывает RTP-сессию стрима, из-за чего подключенные зрители получают **WebRTC ICE Disconnect / Error 2007**!
- **Решение**:
  1. Добавить мемоизацию `lastVoiceConnectState` в UI — не вызывать IPC `voice_connect`, если параметры не изменились.
  2. В `discord-voice` реализовать обработку RTCP PLI/FIR (Picture Loss Indication) от медиа-сервера для генерации ключевых кадров (IDR) без сброса соединения.
  3. Стабилизировать SSRC и временные метки RTP (90 kHz).

### Причина 3: Паритет интерфейса предпросмотра голосового канала (Voice Stage Banner)
В официальном клиенте Discord клик по голосовому каналу в списке не подключает пользователя принудительно, если он находится в текстовом чате: открывается сцена предпросмотра с аватарами участников и кнопкой «Присоединиться к голосовому каналу».
- **Решение**: Добавить плашку предпросмотра сцены с кнопкой входа и счетчиком участников.
