# DESIGN-PARITY — расположение, масштаб, смещения

Дата: 2026-10-24. Владелец: G3 Design + G2 Frontend, приёмка G6/G4.
Источник истины: `waves/RW-39/DESIGN/SPEC.md` §5, `ui/tokens.css`, dump-скриншоты.
Никаких значений «на глаз»: каждое — `[L]`/`[T]`/`[M]`/`[A]` с источником.
Здесь `[T]` — **значение токена** (дизайн-конвенция), а не evidence-уровень G6;
в G6-матрице используются только `[L]/[S]/[D]/[M]/[A]`.

## 1. Что именно проверяем

| Категория | Проверка |
|---|---|
| Расположение | rail/tree/chat/member на своих местах, порядок DOM, отсутствие наложений |
| Размеры | ширины/высоты shell, header, composer, строк, карточек |
| Смещения | gutter 64, padding 16, row padding, отступы панелей, scrollbar |
| Масштаб | 100/125/150/200%: нет обрезания, наложения, горизонтального скролла |
| Окно | 960×600, 1280×820, 1440×900, 1920×1080, 2048×эталон |
| Адаптив | breakpoints 1600/1200/960/720, скрытие member/tree по SPEC |
| Слои | модалки/поповеры в viewport, z-index, focus-ring не обрезан |
| Код | flex/grid; `min-width:0`; `min-height:0`; нет магии вне tokens |

## 4. Как исправлять

1. **DP-01**: добавить `@media (max-width:1599px)`/`(max-width:1199px)`/`(max-width:959px)`/
   `(max-width:719px)` строго по `SPEC.md` §5.1; member hidden 960–1199, tree 200 720–959,
   tree hidden <720; chat `min-width:0`, но не ниже 520 до скрытия.
2. **DP-02**: перейти на D-04: переменная высота 26/48 + 22×переносы, member 42; обновить
   `virtual-list`/height index и тесты **по оракулу**, не подгонкой.
3. **DP-03**: проверить overlay при 960×600 и 200%; max-width 720; внутренний скролл.
4. **DP-04**: добавить probe: 5 viewport × 4 zoom; `getBoundingClientRect`; допуск
   из SPEC; скриншот-дифф; тест падает при наложении/overflow.
5. **DP-05**: meta-тест: при resize 1280→960 member скрыт, 960→720 tree 200, 720→<720
   tree hidden; проверить `aria-hidden`.

## 5. Критерии приёмки дизайна

- [ ] все 5 viewport без горизонтального скролла shell;
- [ ] 200% zoom: нет обрезанных текстов/кнопок/фокуса;
- [ ] rail/tree/chat/member размеры совпадают с SPEC в допуске;
- [ ] gutter 64, padding 16, строки 26/48/42 (D-04);
- [ ] breakpoints работают, member/tree скрываются по правилам;
- [ ] модалка/поповер не выходят за viewport, скролл внутри;
- [ ] DOM-порядок и aria не ломаются;
- [ ] тесты не ослаблены; G6 reviewer подтвердил.

## 6. Что запрещено

- подгонять значения под текущие тесты;
- использовать `transform: scale()` для «масштабирования» вместо CSS layout;
- абсолютное позиционирование shell вместо flex/grid;
- магические px вне tokens без `[L]`/`[T]`/`[M]`/`[A]`;
- объявлять дизайн-паритет по одному скриншоту без матрицы viewport/zoom.
