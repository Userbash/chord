# LESSONS — обучение на собственном коде

Дата: 2026-10-24. PM. Один урок = причина → паттерн → prevention → тест/правило.
Не дублировать DECISIONS; здесь только переносимые выводы.

## L-001. Флаг схемы не равен доказательству

**Причина:** `confirmed:false` в `rest-static.json` был принят за «не подтверждено»,
но стоял у всех 904 записей, включая live-проверенные endpoint'ы.
**Паттерн:** поле-заглушка без вариативности не является evidence.
**Prevention:** проверять распределение поля по всему датасету; использовать
`[L]/[S]/[D]/[M]/[A]` и источник.
**Защита:** G6-устав §4; матрица без колонки `confirmed`.

## L-002. Targeted-тесты не заменяют полный gate

**Причина:** DP-01 дал зелёные targeted-тесты и `tsc` UI, но полный `typecheck`
упал на новом мета-тесте (`TS2532`); gate был red.
**Паттерн:** локальная зелёная зона скрывает ошибку в другом слое.
**Prevention:** после нового test-файла — `npm run typecheck` + полный `gate:release`.
**Защита:** DP-01/D-78; gate обязателен.

## L-003. Синонимы команд увеличивают поверхность

**Причина:** `join_guild` и `enter_guild` — два Tauri command над одним контрактом.
**Паттерн:** «удобный alias» создаёт два API, два места для ошибок и тестов.
**Prevention:** один command + UI-алиас на уровне вызова; удалять duplicate после теста.
**Защита:** Q-01; `guilds_contract.rs`.

## L-004. Большой тест-файл замедляет диагностику

**Причина:** `gui-spike-features.test.mjs` 2303 строки; падение сложно локализовать.
**Паттерн:** монолитный test suite скрывает причинно-следственную связь.
**Prevention:** split by feature/flow, общий harness; не ослаблять assert.
**Защита:** Q-03; meta test-policy.

## L-005. Статический CSS-тест не равен визуальному паритету

**Причина:** DP-01 проверяет media-query/каскад, но не реальные `getBoundingClientRect`
при 200% zoom.
**Паттерн:** текстовый тест подтверждает правило, не результат раскладки.
**Prevention:** DP-04 viewport/zoom probe + screenshot diff; static test — только дополнение.
**Защита:** `DESIGN-PARITY.md` §13; DP-04.
