# Независимое ревью PASS 4 — G3-TYPING-MARKDOWN-SPEC-PASS4

**Вердикт: PASS.** Замечание PASS 3 о ссылках на отсутствующий `--warning-text` закрыто заменой на существующие токены.

## Проверка пункта PASS 3

- `--warning-text` больше не используется в спецификации.
- Slowmode использует `--text-subtle` для текста и `--warning` для индикатора; оба токена объявлены в `rust/gui-spike/ui/tokens.css`. CSS-пример и таблица §1.4 согласованы по фону `--state-hover` и цвету текста.
- В hover-стиле self-mention используются существующие `--warning` и `--text-on-warning`; для текста ошибки используется существующий `--danger-text`.
- Прежние замечания PASS 3 о контрасте slowmode и токенизации упоминаний не регрессировали: текст slowmode остаётся `--text-subtle`, а `--mention-self-bg` и `--row-mentioned-bg` отсутствуют.

Проверка статическая по PASS 3, обновлённой спецификации и `tokens.css`. Код и тесты не менялись; Cargo не запускался.
