# Независимое ревью PASS 3 — G3-INVITES-MODALS-SPEC-PASS3

**Вердикт: RETURN (P1).** Пункт 3 Pass 2 закрыт; пункт 4 не закрыт: spec использует несуществующий токен `--surface-overlay`.

## Проверка пунктов 3 и 4

3. **P1 — `flags` / `IS_GUEST_INVITE`: закрыто.** В §1.2 поле `flags` прямо исключено из обязательного `[D]` контракта и помечено как опциональное проектное расширение `[A]`; стандартное приглашение не передаёт его. В DOM/матрице T-INV-04 гостевой переключатель также назван опциональным расширением `[A]`, а не поведением, подтверждённым RE. Ссылка на внутреннюю константу приведена только как соответствие проектной адаптации, а не как независимое доказательство контракта Discord.

4. **P1 — token-only / scrim: не закрыто.** В §3.1 строка 439 задаёт `background: var(--surface-overlay)` и называет его нормативным токеном, однако `--surface-overlay` отсутствует в `rust/gui-spike/ui/tokens.css` и в `G05-REST-SPEC.md`. Таким образом, исправление заменило отсутствующий `--dialog-backdrop-bg` на другой отсутствующий токен. Нужен существующий нормативный токен или его объявление в нормативном источнике.

Проверка статическая по PASS2 и указанным спецификациям/источникам токенов. Код и тесты не менялись; Cargo не запускался.
