# Независимое ревью — G3 TYPING-MARKDOWN-SPEC

**Вердикт: вернуть на правку; есть блокирующие противоречия в a11y и токен-контракте.**

- **P1, a11y:** пример блока кода помещает кнопку `.md-code-copy` внутрь `.md-code-header[aria-hidden="true"]` (спецификация, строки 283–287). Это скрывает интерактивную кнопку от accessibility tree, хотя ниже она заявлена как клавиатурно доступный control. Уберите `aria-hidden` с предка либо перенесите его только на декоративное содержимое.
- **P1, токены:** правило §0 требует token binding для всех `font-size`, цветов и отступов, но сама спецификация задаёт inline-code `font-size: 0.875em`, а CSS self-mention и подсветки строк использует прямые `rgb(...)` (§2.1, §3.2). Введите токены для этих значений или явно уточните исключения и приведите правило в соответствие примерам.
- **P1, контраст:** slowmode в dark задаёт `color: var(--warning)` (§1.4), тогда как `THEME-SPEC.md` объявляет `--warning` только заливкой и запрещает применять его как текст/иконку. Выберите текстовый токен для dark и зафиксируйте контраст пары с фоном slowmode.
- **P2, точность:** §1.1 описывает 20px общую высоту, но CSS использует `min-height: 16px` плюс вертикальный padding, а `box-sizing: border-box`; для border-box это не даёт гарантированных 20px. Уточните, какой размер является нормативным.
