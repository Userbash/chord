**CHANGES**

- **P1 — ordered-list rendering can panic on input.** [markdown.rs](/home/user/orca/project/rust/crates/discord-i18n/src/markdown.rs:121) adds the item index to the parsed starting number without checked arithmetic. Reproducer: `18446744073709551615. a\n2. b`. The first number parses as `u64::MAX`; rendering the second item overflows in debug builds. Add a regression test and handle overflow without panicking.

- **P2 — nested lists are flattened, so their structure is lost.** [markdown.rs](/home/user/orca/project/rust/crates/discord-i18n/src/markdown.rs:249) uses `trim_start()` in `list_item`, then groups consecutive same-kind items without tracking indentation or nesting. Reproducer: `- outer\n  - inner` renders as `- outer\n- inner`. The test only checks that a deeply indented list does not panic; it misses the lost nesting. Parse nested items or preserve over-limit nesting as literal text, as TZ-W25b §3 requires.

- **P2 — timestamp styles accept trailing invalid characters.** [markdown.rs](/home/user/orca/project/rust/crates/discord-i18n/src/markdown.rs:493) checks only the first character after the style separator, then accepts the entire token. Reproducer: `<t:1712345678:Rbad>` becomes a `Timestamp` and renders unchanged, despite TZ-W25b §3 requiring an exact allowed style. Reject the token unless the style is exactly one allowed character.

- **P2 — slash-command names bypass the documented syntax and length limit.** [markdown.rs](/home/user/orca/project/rust/crates/discord-i18n/src/markdown.rs:559) accepts any nonempty name before the final colon. The source contract in [i18n-deep.md](/home/user/orca/project/docs/re/i18n-deep.md:116) limits names to specified characters and 32 characters. Reproducer: `</bad name:123>` is parsed as a slash command instead of remaining text. Validate the name against the documented character set and length.

`lib.rs` publicly exposes the markdown module and parser/renderer. The tests cover the basic 23 examples, unsafe URL schemes, HTML-as-text, and some UTF-8 inputs, but do not catch these cases. I did not run commands or modify files.
