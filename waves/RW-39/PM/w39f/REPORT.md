  («Отображение сообщений» / «Компактное» / «Уютное»), но не число тумблеров и не группы (G-02).
- **Offline-группа участников** не попала в срез (панель не докручена); сортировка внутри
  role-группы видна только в коде (G-03, G-04).
- **Категория `flags`** есть в enum, но в видимом рейле её нет (10 из 11) — причина не установлена (G-05).
- **Иконки** people/nature/food/travel/objects минифицированы — переносить только подтверждённые
  Clock/Trophy/GameController/Heart/Flag/Star (G-06).
- **Unread divider / new-messages bar / notice / топик** в референсе отсутствуют — контракты из CSS
  и кода, пиксельной проверки нет (G-07).
- **id строки канала** (`chat-messages-…`) не снят — в спайке остаётся `[A]` (G-08).
