# PM / WINDOW-BUDGET — сколько раз можно открывать живое окно

Причина: RW-38/W39 показали «петлю окна» — воркер открывает окно, тыкает один и тот же
сценарий, закрывает, и так на каждой итерации. Это дорого, флейкует (окно иногда падает
за 1,6–3 с) и не даёт новой информации, если UI не менялся.

## Правило

1. **Итерации — без окна.** Red/green внутри карточки проверяются только детерминированными
   слоями: `node --test tests/unit/gui-spike-dom.test.mjs`, `...model.test.mjs`,
   `...bench.test.mjs`, `npx tsc -p rust/gui-spike/ui/tsconfig.json`,
   `node waves/RW-39/PM/w39c/geometry-check.mjs`. Окно не открывается.
2. **Окно — только на приёмке волны.** `gate:worker` (в нём 2 живых запуска: app smoke и
   AT-SPI/X11-проба) — **один раз** на волну, после того как все воркеры отдали green.
   Повтор gate разрешён только если после него изменился `ui/**` или `src/**`.
3. **Кэш пробы.** Результат живой пробы записывается в
   `waves/RW-39/PM/window-runs.jsonl` с ключом
   `sha256(sorted md5 rust/gui-spike/ui/** + mtime бинаря)`. Тот же ключ — повторный запуск
   запрещён, берётся запись из журнала.
4. **Диагностический запуск.** Один дополнительный запуск разрешён, только если есть
   конкретная live-жалоба (окно не появилось / упало) и в журнале ещё нет записи по этому ключу.
   Результат обязан попасть в журнал с полем `reason`.
5. **Флейк ≠ повод повторять.** Один ретрай допустим, оба результата фиксируются. Второй
   идентичный fail → `LOOP-DETECTED` (см. `LOOP-LEDGER.md`), меняем подход, а не команду.

## Как PM проверяет бюджет

Замер (`.gate/worker-2026-10-23T16-11-53-407Z.json`): весь gate 17,6 с, из них `smoke`
(живое окно) — **17,15 с (97 %)**, остальные стадии вместе 0,44 с. То есть почти всё время
гейта — это открыть/закрыть окно; в цикле это и даёт наблюдаемую петлю.

```bash
# сколько живых запусков уже было в волне
rg -c "window-ready|gui-window-probe" waves/RW-39/PM/window-runs.jsonl waves/RW-38/workers/*/*.log
# ключ текущего UI
node waves/RW-39/PM/window-budget.mjs --key
# записать прогон (после реального запуска)
node waves/RW-39/PM/window-budget.mjs --record --reason "acceptance E5"
```

## Запрещено

- Запускать `scripts/gui-window-probe.py`, `gate:worker` или GUI smoke «на всякий случай».
- Открывать окно для проверки CSS/разметки, которую уже покрывает DOM-тест.
- Маскировать падение окна через `GUI_SPIKE_E2E=0` в приёмочном прогоне (это только для
  локальной итерации и должно быть явно указано в отчёте).
