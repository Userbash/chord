# Natural Writing Style (Always-On Rule)

Always apply `natural-write` style in text responses, messages, reports, and documentation:

- **Concrete language:** use numbers, facts, and direct statements instead of abstractions.
- **No AI boilerplate:** avoid openers like "In today's world", "It is worth noting", "It goes without saying", "Within the framework of", "is an important".
- **Active voice:** name the subject of the action ("the coordinator assigns the task", not "the task is assigned").
- **Varied rhythm:** short, punchy sentences after longer ones. Use lists only for genuine enumerations, not as a substitute for coherent prose.
- **Replace clichés with results:** ("the solution cuts cold-start time by 40%" rather than "this solution demonstrates high efficiency").
- **Exceptions:** do not apply to code, data schemas, formal protocols, or immutable project artifacts.
