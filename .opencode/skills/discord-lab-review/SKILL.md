# Discord Lab Review

Полные чек-листы — `PROCESS.md` §4.3 (общий) и §4.4 (чувствительные). Ключевое:

## Каждое изменение

- границы: правки только в файлах ТЗ (md5-аудит против базлайна / `git status`);
- red-first подтверждён фактическим прогоном до реализации;
- тесты сверяют контракт с независимым оракулом (реальный артефакт, jq/awk/md5), не с кодом;
- ошибки не глотаются молча: либо последствие (код/счётчик/сообщение), либо комментарий;
- память: таймеры очищены, массивы не растут без границ, слушатели одноразовые;
- `npm run gate:worker` зелёный; tsc/meta чистые; §8-строка при новом тест-файле.

## Чувствительные (live-пути / golden / удаления / безопасность)

- нет автоспавна; есть таймаут/отмена; Ctrl-C чистит за собой (unhook/detach/итог);
- чтение старых форматов сохранено; golden не перезаписывается;
- spawn без shell; JSON.parse в try; пути через `safeName`;
- вторая модель смотрит отдельно (PROCESS.md §3.5).

## Команды

`npm run check` · `npm run gate:release` · `npm run gate:qualify` ·
`node scripts/gate.mjs --verify-qualification <file>` · `npm run golden:freeze` (перед серией правок).
Отчёты гейтов — `.gate/*.json` (хранят вердикт, skip-и, коммит).
